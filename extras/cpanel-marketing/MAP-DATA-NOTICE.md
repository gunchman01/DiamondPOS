# Map data notice

The bundled world land outline is derived from Natural Earth 1:110m land, public domain:

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Data terms: https://www.naturalearthdata.com/about/terms-of-use/

Coordinates were projected equirectangularly and rounded to reduce bundle size. No external map tiles are loaded. The outline is for general geographic context, not navigation or geopolitical boundary claims.

Activity geolocation is an optional server-to-server lookup through IPGeolocation.io, under the user's own provider account/terms. City/region labels and coordinates describe a network request estimate; they are not customer addresses or proof of where a person was. Coordinates are rounded to 0.1 degrees before storage. The provider receives the request IP transiently for lookup; the application stores coarse location and a time-limited daily HMAC cache identity, not raw IPs. Hosting/provider logs are controlled separately.
